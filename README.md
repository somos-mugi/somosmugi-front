# SomosMugi

Landing page de SomosMugi creada con Next.js, React y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Deploy en Vercel

1. Subí este repositorio a GitHub, GitLab o Bitbucket.
2. En [Vercel](https://vercel.com/new), importá el repositorio.
3. Vercel detectará Next.js automáticamente. No requiere variables de entorno.
4. Presioná **Deploy**.
